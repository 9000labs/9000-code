<h1 align="center">9000 Code</h1>

<p align="center">
  <strong>The Ultimate Desktop Companion for Claude Code CLI</strong>
</p>

<p align="center">
  Session management, split terminals, remote access — take your Claude Code development experience to the next level
</p>

---

## Features

- **Smart Split Terminal**: 7 layouts with drag-resizable panels
- **Session Browser**: Browse and resume Claude Code sessions
- **Skills & Agents**: Manage and run skills/agents with one click
- **Quick Commands**: Save frequently used commands as buttons
- **Remote Access**: Share terminal via WebSocket
- **File Browser**: Navigate project files directly

---

## Download

Download the latest version from the **[Releases](https://github.com/9000labs/9000-code/releases)** page:

| File | Description |
|------|-------------|
| `9000 Code-x.x.x-x64-Setup.exe` | **Windows Installer** (Recommended) |
| `9000 Code-x.x.x-x64-Portable.exe` | **Windows Portable** (No installation required) |

### System Requirements

| Item | Requirement |
|------|-------------|
| OS | Windows 10 or later |
| Claude Code CLI | Must be installed and in PATH |

---

## Quick Start

1. Download and install from [Releases](https://github.com/9000labs/9000-code/releases)
2. Launch 9000 Code
3. Type `claude` in the terminal to start Claude Code CLI
4. Use the sidebar to browse sessions, skills, and agents
